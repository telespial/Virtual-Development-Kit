# VDK First Demo Recommendation

The first demo should be simple, visual, and credible.

## Suggested Demo
A virtual embedded board that includes:

- one framebuffer-backed display
- one virtual sensor input stream
- one or two simple user inputs
- a host window or dashboard
- a firmware-like loop that reacts to the inputs

## Why this demo
It proves:
- the architecture is real
- the host/device split is correct
- VDK can support EmbeddedX workflows
- the concept is understandable to engineers and customers

## Bad first demos
Avoid these as the very first milestone:
- full ARM core emulation
- trying to mirror an entire dev board
- dozens of peripherals
- timing-perfect instruction simulation

## Deliverables
- demo video or screenshots
- short architecture explanation
- reproducible run steps
